## 문서 기준과 실행 검증

- 문서로 확인: 원문의 옵션 철자·예제·명시된 지원 시점. 개별 절에 범위를 표시했다.
- 현재 배포 폴더 확인: 2026-09-03 기준 이 저장소의 스킬 `${SKILL_ROOT}/assets/tmpa/`에는 `.gitkeep`만 있고 PA 실행 파일은 없다.
- 실제 PA 검증: 이번 문서 정리에서는 수행하지 않았다. 따라서 검증한 PA 버전·실행 파일 해시·옵션별 성공 로그는 없다.

실행 파일은 실제 배포 시 포함하므로 문서의 지원 버전을 현재 바이너리 검증 결과로 표현하지 않는다. 파일이 없으면 [PA 실행 계약](pa-runtime.md)에 따라 `GuidanceOnly`로 안내하며, 있어도 새 실행의 증거로 성공을 확인한다.

문법이 확인된 옵션의 PA 버전만 불명확하면 [PA 실행 계약](pa-runtime.md)에 따라 복사본에서 검증할 수 있다. 문법·허용값 자체를 모르면 추측한 값을 시험하지 않고 해당 후보에 필요한 확인을 보고한다.

## 배포 문서 갱신

1. 유지보수 시 원문 변경분을 확인해 복구 판단에 필요한 설명·표·예제를 로컬 참고서에 반영한다. 출처 ID와 조회일을 함께 갱신한다. 이 절차를 외부 사용자의 실행 조건으로 넣지 않는다.
2. 실제 배포하는 tmpa의 버전 근거·해시와 옵션 검증 로그가 있으면 위 실행 검증 기록을 갱신한다. 확인하지 않은 항목은 계속 미확인으로 남긴다.
3. `SKILL.md`, `references/analysis-guide.md`, `references/pa-options.md`, `references/guide-sources.md`를 기존 스킬 자료와 함께 배포한다. 문서 본문의 필수 링크는 로컬 상대 경로로 유지한다.
4. 배포 폴더의 문서만으로 컴파일러 버전 불일치, target·타입 불일치, 선언 누락을 조사할 수 있는지 점검한다. 인코딩 허용값 미확인 사례에서는 값을 지어내거나 Notion 접근을 요구하지 않는지 확인한다. 문서 점검을 실제 PA 실행 성공으로 기록하지 않는다.
